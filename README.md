# Talenta Resume Studio

Crie o Talenta. A ferramenta será parecida com as outras duas que já criou, quero a mesma tela de login, porém quero aquele aspecto de vidro estilo apple. O slogan será "Seu talento. No formato certo." Descrição: "Leitura, estruturação e padronização de currículos conforme o padrão da empresa". Vou anexar um padrão de currículo, lembre de manter esse logo e layout na saída, terão diversos modelos diferentes de currículos que poderão ser anexados, a regra é única, exportar nas opções .docx e .pdf com o layout deste que te anexei agora, o sistema terá um local para arrastar/selecionar arquivo, e ele fará a leitura do arquivo e devolverá o download neste layout modelo que te passei. A única inclusão será um campo na mesma tela de subir o currículo, que será para a recrutadora incluir um o relato da entrevista com o candidato.
